# Botyard API

Бэкенд платформы, которая разворачивает торговых роботов T-Invest API для клиентов на серверах
под управлением [Dokploy](https://dokploy.com).

Что внутри:

- оркестрируемая сага развёртывания поверх неидемпотентного внешнего API;
- transactional outbox → RabbitMQ, inbox для вебхуков, reconciler для зависших операций;
- машина состояний с условными переходами и тестами гонок;
- envelope encryption секретов клиентов.

Статус: этап 0, дизайн. См. [архитектуру](docs/architecture.md) и [план](docs/roadmap.md).

> Роботы по умолчанию работают в песочнице T-Invest. Платформа не даёт инвестиционных рекомендаций,
> а сторонние роботы используются как пример нагрузки, за их стратегии авторы Botyard не отвечают.
