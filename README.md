# Botyard Admin

Админка платформы Botyard: заводит назначения (Dokploy-инстансы) и клиентов, разворачивает торговых
роботов T-Invest API, показывает их статус и логи.

Статус: каркас появится на этапе 4, см. [план](../api/docs/roadmap.md).

## Экраны

| Экран | Что делает |
|---|---|
| Назначения | Добавить Dokploy-инстанс (URL, API-ключ, окружение, сервер), проверить связь |
| Клиенты | Имя, токен T-Invest, счёт, песочница или боевой режим |
| Развернуть | Клиент → шаблон робота → назначение → конфиг по схеме шаблона |
| Развёртывания | Статус, текущая операция по шагам, история, кнопки start, stop, redeploy, delete |
| Логи | Живые логи контейнера робота (SSE) |
| Аудит | Кто что сделал |
