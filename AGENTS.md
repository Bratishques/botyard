# AGENTS.md — Botyard

Botyard — платформа, которая разворачивает торговых роботов T-Invest API для клиентов через Dokploy.
Монорепозиторий из четырёх частей:

| Папка | Что внутри | Правила |
|---|---|---|
| `api` | бэкенд: админ-API, сага развёртывания, outbox, reconciler. **Здесь же дизайн проекта**: `api/docs/` | `api/AGENTS.md` |
| `admin` | SPA для операторов | `admin/AGENTS.md` |
| `bots` | каталог манифестов роботов | `bots/AGENTS.md` |
| `infra` | dev-окружение, установка Dokploy | `infra/AGENTS.md` |

Перед работой прочитать `AGENTS.md` той части, где идёт правка, и `api/docs/architecture.md`.

Правила подготовки, проверки, ревью и разбора ошибок общие для всех частей и лежат в `api/.agents`:
навыки `botyard-prepare`, `botyard-verify`, `botyard-error-learning`, правила гонок
`api/.agents/rules/race-conditions.md`, реестр уроков `api/.agents/knowledge/lessons/agent-errors.md`.
Для Claude Code навыки доступны через симлинк `.claude/skills`.

## Общие правила

- Bun везде: api, админка, скрипты, CI. Node.js и npm не используются.
- Проект публичный (витрина на GitHub). Никакого кода, текстов и данных из коммерческих проектов
  владельца: подходы можно, исходники нельзя.
- Факты о внешних системах (Dokploy API, роботы, T-Invest API) проверяются по первоисточнику, а не по
  памяти, со ссылкой и датой проверки.
- Песочница T-Invest — режим по умолчанию везде: в шаблонах, тестах, демо.
- Секреты не попадают ни в git, ни в логи, ни в фикстуры. Фикстуры с живого Dokploy чистятся от ключей
  и токенов до коммита.
- Коммит — по разрешению владельца. Push и публикация — только по отдельной явной просьбе.
- Порядок веток, коммитов и завершения задачи — раздел «Git и завершение задачи» в `api/AGENTS.md`.

## Монорепо

Turborepo + workspaces Bun (`package.json`, `turbo.json` в корне). Пакеты: `api`, `admin` (`@botyard/admin`),
`packages/*` (сейчас `@botyard/contract`).
- Зависимости — `bun install` в корне; общие версии — `workspaces.catalog`, в пакете — `"catalog:"`.
- Проверка всего — `bun run check` в корне (lint, typecheck, test по графу, с кешем); интеграционные —
  `bun run test:int` (без кеша); сборка админки — `bun run build` (turbo, выход `admin/dist`). Внутри пакета его собственные скрипты работают как раньше.
- Схемы тел запросов и формы ответов API живут в `@botyard/contract`, а не в контроллерах: контроллер берёт
  схему оттуда, функция ответа возвращает тип контракта — расхождение с доменом ловит `tsc`.
- Biome: общий стиль — корневой `biome.json`, в пакете — `"extends": "//"` и свои `files.includes`.
