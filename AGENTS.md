# AGENTS.md — botyard/bots

Каталог манифестов роботов. Кода нет, только JSON-манифесты и шаблоны конфигов.

- Каждый манифест обязан проходить `schema/template.schema.json`.
- Код upstream не копировать и не вендорить. Если нужна правка — форк с минимальным изменением,
  а в манифесте ссылка на форк и в `notes` — что и почему изменено.
- Факты о роботе (пути, переменные, порты) проверяются по upstream, а не угадываются. Ссылку на файл,
  где факт виден, записать в `notes`.
- Шаблоны — Handlebars. Секреты только через `secret.*`, в манифест не вписываются никогда.
- Значения по умолчанию безопасные: песочница, минимальный объём заявки.
