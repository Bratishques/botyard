# @botyard/contract

Контракт админ-API Botyard: схемы тел запросов (zod) и формы ответов. Один источник для `api` (проверка
входа в контроллерах) и админки (формы и типы ответов, этап 4).

- Пакет без сборки: экспортирует TypeScript, его читают Bun и Vite.
- Ответы — интерфейсы. `api` собирает ответ из домена функцией, возвращающей тип контракта, поэтому
  расхождение домена и контракта ловит `tsc`.
- Человекочитаемое описание ручек и кодов ошибок — `api/docs/api-contract.md`.
